# 🌍 Sea n Seek Planner

> **Plan smarter. Explore better. Travel with confidence.**

Sea n Seek Planner is a modern travel planning web application designed to make trip planning easier, more organized, and more visual.

The platform brings trip planning, itineraries, destinations, maps, activities, saved trips, and travel information together in a single workspace.

Built with React, TypeScript, Vite, Tailwind CSS, Supabase, Leaflet, and modern UI libraries, the project focuses on creating a practical and scalable travel-planning experience.

## ✨ Features

### 🗺️ Trip Planning

Create and organize travel plans from a centralized interface.

- Create trips
- Add destinations
- Organize travel activities
- Plan day-by-day itineraries
- Manage trip information
- Track important travel details
